# 🏝️ ISLAND

**ISLAND** é um jogo desenvolvido na Unity para a disciplina de **Realidade Virtual (RV)**, como parte de um projeto acadêmico.

O jogo é uma aventura de exploração em primeira pessoa, ambientada em uma ilha misteriosa repleta de templos antigos, tesouros escondidos, armadilhas e inimigos. O jogador deverá explorar o ambiente, superar desafios e enfrentar perigos para encontrar os tesouros espalhados pela ilha.

## 🎮 Sobre o jogo

O objetivo é explorar a ilha, descobrir seus segredos e encontrar os tesouros escondidos em diferentes locais do cenário.

Durante a aventura, o jogador precisará atravessar ambientes, explorar templos, desviar de armadilhas e lidar com inimigos que podem dificultar sua jornada.

A exploração é realizada em primeira pessoa, proporcionando uma experiência de imersão no ambiente 3D.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| **W** | Andar para frente |
| **A** | Andar para a esquerda |
| **S** | Andar para trás |
| **D** | Andar para a direita |
| **Shift** | Correr |
| **Espaço** | Pular |
| **Mouse** | Controlar a câmera e a visão do personagem |

## ✨ Funcionalidades

- Movimentação do personagem em primeira pessoa.
- Controle da câmera utilizando o mouse.
- Sistema de corrida e pulo.
- Exploração de uma ilha em ambiente 3D.
- Templos e estruturas antigas espalhadas pelo cenário.
- Tesouros escondidos para encontrar durante a exploração.
- Armadilhas e obstáculos que desafiam o jogador.
- Presença de inimigos durante a aventura.
- Ambiente temático de exploração e aventura.

## 🛠️ Tecnologias utilizadas

- **Unity** — desenvolvimento do jogo e criação do ambiente 3D.
- **C#** — programação das mecânicas e comportamentos do jogo.
- **Blender** — criação e edição de modelos 3D, quando aplicável.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/ErikMazzuco/JOGO-ISLAND
   ```

2. Abra o Unity Hub.
3. Selecione a opção para adicionar ou abrir um projeto existente.
4. Escolha a pasta do projeto clonado.
5. Abra o projeto com uma versão compatível da Unity.
6. Abra a cena principal e clique em **Play** para iniciar o jogo.

## 🎓 Objetivo acadêmico

O projeto foi desenvolvido para a disciplina de Realidade Virtual, com o objetivo de aplicar conhecimentos de desenvolvimento de jogos 3D, programação, movimentação de personagens, colisões e interação com objetos em um ambiente virtual.

A proposta busca desenvolver uma experiência de exploração em primeira pessoa, utilizando elementos de aventura para proporcionar desafios e interação com o cenário.
