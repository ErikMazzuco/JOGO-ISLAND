# 🏝️ ISLAND

**ISLAND** é um jogo desenvolvido na Unity para a disciplina de **Realidade Virtual (RV)**, como parte de um projeto acadêmico.

É uma aventura de exploração em primeira pessoa, ambientada em uma ilha misteriosa repleta de templos antigos, tesouros escondidos, armadilhas e inimigos. O jogador deve explorar o ambiente, superar desafios e enfrentar perigos para encontrar os tesouros espalhados pela ilha.

## 🎮 Sobre o jogo

O objetivo é explorar a ilha, descobrir seus segredos e encontrar os tesouros escondidos em diferentes locais do cenário.

Durante a aventura, o jogador atravessa ambientes, explora templos, colete moedas e itens de cura e enfrenta esqueletos que dificultam a jornada. Se a vida chegar a zero, é fim de jogo: é possível renascer ou voltar ao menu.

A exploração é feita em primeira pessoa, para uma experiência imersiva no ambiente 3D.

## ✨ Funcionalidades

**Jogabilidade**
- Movimentação em primeira pessoa, com câmera pelo mouse, corrida e pulo.
- Combate com espada, com animação e som. O golpe acerta onde está a mira.
- Mira em forma de bolinha no centro da tela, que fica vermelha quando há um inimigo ao alcance.
- Esqueletos inimigos que perseguem e atacam o jogador. Ao morrer, caem no chão e desaparecem aos poucos.
- Moedas coletáveis que giram e flutuam, com som ao pegar.
- Itens de cura que recuperam a vida do jogador.
- Exploração de uma ilha 3D com templos e estruturas antigas.

**Interface**
- Barra de vida com número, efeito ao levar dano e alerta de vida baixa.
- Contador de moedas na tela.
- Tela de fim de jogo com os botões **Renascer** e **Menu**.
- Minimapa redondo que gira com o jogador, com marcadores de moedas, itens de cura e inimigos.
- Menu inicial com fundo animado (cachoeira, mar, plantas, tochas e pássaros).

**Opções**
- Contador de FPS (ligado por padrão).
- Qualidade gráfica: Baixa, Média ou Alta.
- Sombras: ligar ou desligar.
- Distância de renderização ajustável.
- Sensibilidade do mouse.
- As escolhas ficam salvas no computador.

**Áudio**
- Passos, espada, dano e morte do jogador, sons dos inimigos, ambiente, animais e menu.

## 🛠️ Tecnologias utilizadas

- **Unity 6** (6000.0.75f1) com **Universal Render Pipeline (URP)**: desenvolvimento do jogo e do ambiente 3D.
- **C#**: programação das mecânicas e comportamentos do jogo.
- **TextMesh Pro**: textos da interface.
- **Blender**: criação e edição de modelos 3D, quando aplicável.

## 📥 Download

Quer jogar ISLAND?

**[Baixar ISLAND para Windows](https://github.com/ErikMazzuco/JOGO-ISLAND/releases/latest)**

1. Baixe o arquivo ZIP da versão mais recente.
2. Extraia todos os arquivos para uma pasta.
3. Execute `ISLAND.exe` para começar a jogar.

> **Dica:** se o jogo estiver pesado no seu computador, abra **Opções** no menu inicial e coloque a qualidade em **Baixa**, desligue as sombras ou diminua a distância de visão.

*Observação: o jogo deve ser executado no Windows e pode exibir um aviso de segurança por ser um aplicativo não assinado.*

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/ErikMazzuco/JOGO-ISLAND
   ```

2. Abra o Unity Hub.
3. Selecione a opção para adicionar ou abrir um projeto existente.
4. Escolha a pasta do projeto clonado.
5. Abra o projeto com a Unity **6000.0.75f1** (ou uma versão compatível).
6. Abra a cena **Menu** (`Assets/Scenes/Menu`) e clique em **Play** para iniciar o jogo.

## 🎓 Objetivo acadêmico

O projeto foi desenvolvido para a disciplina de Realidade Virtual, com o objetivo de aplicar conhecimentos de desenvolvimento de jogos 3D, programação, movimentação de personagens, colisões, inteligência de inimigos, interface e interação com objetos em um ambiente virtual.

A proposta busca desenvolver uma experiência de exploração em primeira pessoa, utilizando elementos de aventura para proporcionar desafios e interação com o cenário.
